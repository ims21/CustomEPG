	<<< CustomEPG >>>

A plugin for displaying the EPG of selected channels (either individually selected from bouquets or imported from an entire bouquet, with the option to save the selection), with their programmes displayed continuously in a single list.

The settings allow you to filter programmes by duration, so you can exclude short programmes and see only movies, or conversely, limit the maximum duration to display only shorter programmes. You can also choose whether to display recently finished programmes, currently running programmes, or only upcoming ones.

The plugin is particularly useful for scheduling timers. It also supports displaying and editing timers on remote receivers via Partnerbox, provided the Partnerbox plugin is installed.
